# Interview Preparation

**Why Firebase?** Managed authentication, document database, storage and serverless functions reduce infrastructure overhead for a student portfolio while demonstrating cloud primitives.

**Why a Cloud Function between ESP32 and Firestore?** It keeps privileged Admin SDK credentials off the device and provides a validation boundary for telemetry.

**How does real-time work?** Firestore `onSnapshot()` subscribes to changes and updates the React state when a new scale document is written.

**What happens if an AI API is unavailable?** The local deterministic recommendation engine generates a structured fallback plan, so the application remains demonstrable.

**What would you improve for production?** Hardware TLS certificate validation, stronger device identity/rotation, server-side schema validation, rate limiting, observability, stricter nutrition provenance, and a dedicated managed AI gateway.
